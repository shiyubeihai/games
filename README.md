# games
# （仓库名）

A small collection of puzzle games, made for fun.

- **Solo-made** — designed and built by one person
- **Single-player** — no accounts, no waiting
- **Works offline** — everything runs locally
- **No ads** — nothing between you and the games

## Games

| Game | What it is |
|---|---|
| **gem2048** | Slide and merge gems to reach 2048. |
| **flowers2048** | A floral take on 2048 — merge blooms to reach 2048. |
| **tiangan1024** | Merge tiles marked with the ten **Celestial Stems** and reach 1024. |
| **dizhi4096** | Merge tiles marked with the twelve **Terrestrial Branches** and reach 4096. |
| **fibonacci233** | Add adjacent numbers into their sum, follow the Fibonacci sequence, and reach 233. |

## A note on the numbers

The targets are not arbitrary:

- **1024** is 2¹⁰ — the ten Celestial Stems (天干)
- **4096** is 2¹² — the twelve Terrestrial Branches (地支)
- **233** is F₁₃, the thirteenth Fibonacci number
- **2048** is 2¹¹, the familiar classic

Each game's theme decides how many distinct tiles exist, and that in turn decides the goal.
